# KODA Care

Static React prototype reproducing the provided KODA Care / E-Hospital reference screens. It intentionally preserves the source layout, copy, proportions, and visible quirks. It is not a clinical system and has no authentication, persistence, or deployment backend.

## Run locally

```bash
npm install
npm start
```

## Prototype routes

`#welcome`, `#mission`, `#entry`, `#phone`, `#verify`, `#password`, `#dashboard`, `#records`, and `#details`.
